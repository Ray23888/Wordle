Python Command Line Wordle Game

A command-line clone of the popular Wordle word game built entirely in Python.

This project was completed as part of a structured programming or learning initiative, developed under the specific guidance of a Google Instructor. It demonstrates fundamental Python concepts, including file handling, loop control, object-oriented programming (classes for statistics), and complex logic (the two-pass Wordle analysis).

Features

    Accurate Wordle Logic: Implements the correct two-pass logic to handle duplicate letters and ensure accurate coloring (Green, Yellow, Gray).

    Color-Coded Feedback: Uses ANSI terminal codes for colored output.

    Guess Validation: Only accepts 5-letter words found within the provided dictionary file.

    Game Statistics: Tracks and displays detailed stats, including:

        Total Games, Wins, and Losses.

        Win Percentage and Average Guesses per Win.

        Guess Distribution (how many games were won in 1 guess, 2 guesses, etc.).

    Play Again: Offers a simple prompt to restart the game and track ongoing statistics.
